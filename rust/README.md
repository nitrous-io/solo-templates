### Rust

This project comes with `multirust` to help you manage Rust versions, and has Rust and Cargo pre-installed.

To see which version of Rust is installed, run: `rustc -V`

To update to latest Rust stable, run: `multirust update stable && multirust default stable`

For more information, please consult the [multirust README](https://github.com/brson/multirust/blob/master/README.md)
